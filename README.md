# Mansha Bhardwaj — Portfolio Website

## What is included
- `index.html` — complete one-page portfolio
- `arena-os.html` — detailed ARENA OS / Make.com automation case study
- `assets/Mansha_Bhardwaj_CV.pdf` — clickable CV
- `assets/Online_Gaming_Sector_Map.pdf` — clickable research project

## Fastest way to publish
### Netlify
1. Unzip this folder.
2. Go to Netlify Drop.
3. Drag the `mansha_portfolio` folder into the browser.
4. Netlify will generate a public URL.

### GitHub Pages / Vercel
Upload the folder as a static site. `index.html` is already at the root.

## Design direction
Editorial / consulting-grade interface with subtle fashion-magazine and film-credit references:
- cream / wine / plum palette
- editorial serif display type
- “Issue 01”, “Intermission”, and “End credits” as restrained creative cues
- no heavy visual gimmicks that compromise recruiter readability

## Important note
The raw Make.com blueprint contained connection identifiers and email/account metadata, so the public site uses a sanitized case-study page rather than publishing the raw blueprint.
